# Aurum — Injury & Kit Detection Model

YOLO-based object detection model trained on 7 classes:
lacerations, open wounds, syringes, hemostatic gauze, 
tourniquets, butterfly tape, and bandages.

Built as part of the Aurum applied project — an AR emergency 
response system for high-risk adventurers.

Live demo: https://kjain58-design.github.io/Applied_Project_Vita_M/model/
